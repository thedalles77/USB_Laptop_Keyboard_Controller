The macbook_a1286_default.uf2 file was created by the QMK compiler, using the files 
in the macbook_a1286 folder. If you don't want to make any changes (or learn how to 
use QMK), you can put the Pico into loader mode and drag the .uf2 file into the Pico 
folder. This .uf2 file only works if you have a macbook pro a1286 keyboard. Any other keyboard
will have a different key matrix, requiring modifications to the files and a new QMK compile.
